# TESTS.md — ручные сценарии проверки

| № | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Открыть вкладку "Каталог аудиторий" | Отображаются таблицы аудиторий и инвентаря |
| 2 | Открыть вкладку "Управление бронированием" | Отображается лента броней |
| 3 | Нажать "Новая бронь", заполнить форму, сохранить | Бронь появляется в ленте |
| 4 | Создать бронь с интервалом, пересекающимся с существующей для того же ресурса | Кнопка "Создать" заблокирована, показано предупреждение; при попытке отправить напрямую на backend — ответ 409/400 |
| 5 | Отфильтровать брони по дате | В ленте остаются только брони на выбранную дату |
| 6 | Отфильтровать по типу ресурса "Аудитория" | В ленте остаются только брони аудиторий |
| 7 | Найти бронь по подстроке в названии | Лента сужается до совпадений |
| 8 | Редактировать существующую бронь | Изменения сохраняются, время корректно конвертируется UTC↔локальное |
| 9 | Удалить бронь | Бронь пропадает из ленты |
| 10 | Экспорт JSON | Скачивается файл с rooms/assets/bookings |
| 11 | Импорт ранее экспортированного JSON | Брони в сторе заменяются данными из файла |
| 12 | Запуск на Windows (`npm run dev` / Docker) | Приложение работает идентично Linux |
| 13 | Запуск на Linux (`npm run dev` / Docker) | Приложение работает идентично Windows |
