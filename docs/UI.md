# UI.md — описание экранов

## 1. Каталог ресурсов (`pages/Catalog/CatalogPage.tsx`)
Две таблицы: аудитории (номер, название, вместимость, оборудование, статус) и инвентарь
(инв. номер, название, статус). Доступ — вкладка "Каталог аудиторий" в шапке.

## 2. Лента броней (`pages/Bookings/BookingsPage.tsx`)
Таблица броней с фильтрами: текстовый поиск по названию/примечанию, фильтр по дате, фильтр по
типу ресурса (аудитория/инвентарь). Кнопки: "Новая бронь", "Экспорт JSON", "Импорт JSON".
Для каждой брони — действия "Редактировать" / "Удалить".

## 3. Форма создания/редактирования брони (`components/BookingForm`)
Открывается диалогом поверх ленты броней. Поля: тип ресурса, ID ресурса, название, начало/
окончание (datetime-local, интерпретируется в локальной таймзоне и переводится в UTC при
отправке), примечание. При обнаружении пересечения с существующей бронью того же ресурса —
кнопка "Создать/Сохранить" блокируется, показывается предупреждение.
